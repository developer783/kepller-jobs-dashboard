Mercor Job Search

Search Mercor jobs by relevance, recency, and export results as CSV.

Search parameters
orderBy – "search", "newest", "oldest". Note: when using "newest" or "oldest", the searchQuery is ignored by Mercor.
searchQuery – only used when orderBy = search. Ranks jobs by relevancy but does NOT filter them out.
timeRange – "all", "30d", "7d", "24h"
limit – max number of jobs after filtering (1–1000)
